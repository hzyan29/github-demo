# github-demo

我的第一个 GitHub 仓库，用来练习 Git 的基本操作。

## 这是什么

一个极简的 Python 项目，只做一件事：打印一句问候语。

## 怎么运行

需要 Python 3.8 或更高版本。

```bash
python hello.py          # 问候世界
python hello.py 小明     # 问候指定的人
```

输出：

```
你好，世界！欢迎来到 GitHub。
```

## 我在这里练了什么

- [x] `git init` 初始化仓库
- [x] `git add` 暂存文件
- [x] `git commit` 提交
- [x] `git push` 推送到 GitHub
- [x] 建分支、合并
- [x] 提一个 Pull Request
